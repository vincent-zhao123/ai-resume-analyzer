# AI Resume Analyzer

Cloud-native AI resume analysis platform built with React, Node.js, and AWS.

## Features

- Resume PDF upload
- AI-powered resume analysis
- ATS keyword extraction
- Match score generation
- Resume bullet rewriting
- Interview question generation
- Analysis history dashboard

## AWS Services Used

- Amazon Bedrock (Nova Lite)
- Amazon S3
- Amazon DynamoDB

## Tech Stack

Frontend:
- React
- Axios
- Vite

Backend:
- Node.js
- Express
- Multer

Cloud & AI:
- AWS Bedrock
- S3
- DynamoDB
